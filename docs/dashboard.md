# VolatiAI Dashboard  
Hybrid Tone — Technical + Expressive

The VolatiAI Dashboard is the visual interface for the unified intelligence snapshot generated by the Local Runner.  
It displays trend acceleration, narrative velocity, whale pressure, spoofing probability, chain truth, sector growth, and ecosystem stress — all rendered locally, without servers or telemetry.

The dashboard is intentionally:

- offline  
- local  
- serverless  
- stateless  
- anti‑compliance  
- lightweight  

It reads static files generated by the Local Runner and requires no backend.

---

# 📊 Dashboard Files

The dashboard uses four key files:

### **1. intel.json**
Raw intelligence snapshot containing all fused signals.

### **2. intel.html**
Full dashboard view with charts, indicators, and multi‑signal summaries.

### **3. summary.html**
Condensed dashboard view for quick scanning.

### **4. latest.json**
Minimal snapshot for automation, scripting, or external tools.

These files are generated by:

```bash
npm run local
