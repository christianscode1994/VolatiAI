# Data source attribution

VolatiAI aggregates public data from the following sources. All sources
are either U.S. federal government public domain, CC0, or CC BY 4.0
(permissive open licenses with attribution).

## U.S. Federal Government — public domain (17 U.S.C. § 105)

- NWS (weather alerts)
- USGS (earthquake monitoring)
- NOAA SWPC (space weather)
- SEC EDGAR (company filings)
- FDIC (banking data)
- CDC (public health)
- U.S. Census Bureau (population)
- BTS (freight and border crossings)
- MISO (Midwest grid operator)
- Federal Register

## CC0 (public domain dedication)

- **GLEIF** (legal entity identifiers) — CC0

## CC BY 4.0 (attribution required — credit in bot footer or /sources command)

- **World Bank** (economic indicators)
- **Eurostat** (EU statistics)
- **GBIF** (biodiversity)
- **OBIS** (marine species)
- **BFS Swiss** (Swiss statistics)
- **PRH Finland** (company registry)
- **UK Carbon Intensity** — National Energy System Operator
- **Energinet** (Danish grid)
- **GeoNet NZ** (earthquakes, volcanoes) — GNS Science
- **Open-Meteo** (weather and marine)
- **Crossref** (academic metadata)
- **NHM London** (natural history datasets)
- **iDigBio** (museum specimens)
- **OpenLibrary** (public-domain books)

## MIT (permissive)

- **Gutendex** (Project Gutenberg index)

## Other permissive / open

- **FRED** (if used) — public
- **Frankfurter** (ECB rates) — public
- **GDACS** (EU/JRC disasters) — permissive
- **DataFirst** (African microdata) — open repository
- **OpenSanctions** (if used) — see source terms
- **LangPop** — open data
- **RandomUser** — public API
- **Sunrise-Sunset** — public API
- **Zippopotam** — public API

## Removed sources (previous versions)

The following were removed to eliminate compliance risk:

- **WHO GHO** — CC BY-NC-SA (non-commercial restriction)
- **TVmaze** — CC BY-SA (share-alike restriction)
- **CoinPaprika, CoinMarketCap, WhiteBIT, DexPaprika, Dailymotion** —
  commercial ToS (redistribution prohibited)
- **Lockbox Seeds** — non-commercial + cite-required
- **Several unverified community APIs** — license status unclear
