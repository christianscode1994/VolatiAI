Thank you for your interest in contributing to VolatiAI!  
This project is intentionally **serverless**, **stateless**, **offline‑capable**, and **anti‑compliance**.

---

# 🌐 Contribution Philosophy

VolatiAI must remain:

- local  
- offline‑capable  
- serverless  
- stateless  
- non‑tracking  
- non‑identifying  
- anti‑compliance  

No contribution may introduce:

- accounts  
- subscriptions  
- telemetry  
- analytics  
- cloud dependencies  
- identity systems  
- compliance overhead
