# VolatiAI — Top-Level Architecture

## Mission
VolatiAI is a serverless AI/DePIN intelligence engine that combines:
- market volatility
- social sentiment
- developer activity
- exchange depth

It produces autonomous, agentic intelligence snapshots for chains, ecosystems,
and narratives.

---

## Core Principles
- Fully serverless
- Stateless compute
- Event-driven pipeline
- Internal agent economy
- Non-financial scoring (VAI-INT)
- Modular architecture
- Multi-signal fusion
- Autonomous truth arbitration

---

## High-Level Architecture

### 1. Data Layer
Collects raw signals from:
- exchanges
- social platforms
- developer ecosystems
- liquidity sources

### 2. Valuation Layer
Normalizes raw signals into ValuatedSignal packets.

### 3. Agent Layer
Autonomous agents:
- Signal Agents
- Fusion Agents
- Arbitration Agents
- Mission Agents

Agents use VAI-INT and capabilities to bid, execute, arbitrate, and evolve.

### 4. Mission Layer
MissionSpec defines tasks such as:
- rank volatility
- detect anomalies
- compute chain health
- generate intelligence summaries

MissionExecutor orchestrates bidding → execution → arbitration → rewards.

### 5. Intelligence Layer
Outputs:
- chain intelligence snapshots
- volatility rankings
- sentiment maps
- dev velocity indicators
- liquidity stress alerts

### 6. Presentation Layer
Used by:
- dashboards
- alerts
- API endpoints
- agent consumers

---

## Safety Model
VolatiAI is:
- non-financial
- non-tokenized
- non-redeemable
- non-tradable
- purely internal scoring
- legally safe under serverless hobby project classification

---

## Summary
VolatiAI is a fully autonomous, multi-signal, agentic intelligence engine built
on serverless principles. Its internal agent economy enables continuous
self-optimization without financial exposure or regulatory risk.
