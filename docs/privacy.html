Privacy Policy

Last updated: 2026-10-27

The short version

VolatiAI is stateless. We don't have user accounts, don't set cookies, don't track you, and don't sell data. There is nothing to delete because nothing is stored about you.

What we do

  • Publish aggregate signals about public data sources (government statistics, open APIs, etc.).
  • Run on Cloudflare Workers, which is stateless by design.

What we don't do

  • No user accounts, no login, no email collection.
  • No cookies, no tracking pixels, no analytics SDKs.
  • No selling or sharing of visitor data — there is no visitor data to sell.
  • No ads.

What Cloudflare sees

Because the site is hosted on Cloudflare, Cloudflare's infrastructure processes every request. Per Cloudflare's privacy policy, they may log IP addresses and basic request metadata for security and abuse prevention. This logging is temporary (typically < 30 days) and we do not have access to it.

If you want to avoid even this minimal logging, use a VPN or a browser with a proxy. The content is public and identical regardless.

Third-party sources

VolatiAI fetches data from dozens of public APIs (NASA, USGS, WHO, World Bank, Open-Meteo, MusicBrainz, and others). Each retains its own privacy policy and terms. Our attribution file lists the licenses and sources. None of these APIs receive visitor data from VolatiAI — we call them server-side, not from your browser.

Children

Not directed at children under 13. No data collection of any kind, so no COPPA/GDPR-K concerns.

Changes

If this policy changes, the "Last updated" date will change. The principles (stateless, no tracking, no accounts) are structural and unlikely to change.

Contact

For privacy questions, open an issue at the project repository.

This policy is deliberately simple because the architecture is deliberately simple. VolatiAI stores nothing about visitors, so there is nothing to protect.
