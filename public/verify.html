Verify a VolatiAI file

Every published data file has a companion .sha256 file containing its SHA-256 hash. If the hash of what you downloaded matches, the file has not been altered in transit.

Content integrity

curl -sS https://christianscode1994.github.io/VolatiAI/intel.json | sha256sum
curl -sS https://christianscode1994.github.io/VolatiAI/intel.json.sha256

The first command prints a hash and a filename; the second prints the expected hash. If they match, the file is intact.

Identity anchor

The canonical identity is the Nostr pubkey documented in identity.json. If a post on another platform (Telegram, Discord, Bluesky, Mastodon, Slack) claims to be VolatiAI, cross-reference the identity document to check whether that claim is consistent with the canonical pubkey.

Compliance framing
